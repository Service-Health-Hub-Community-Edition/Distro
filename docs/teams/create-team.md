## Creating a Team

Log on to Microsoft Teams and create at least two new teams with the following parameters.

### Microsoft Service Health Hub

- **Create a team:** From scratch
- **Kind of team:** Private
- **Team name:** Microsoft Service Health Hub
- **Description and Classification:** Leave the default values

### Microsoft Service Health Hub Admin

- **Create a team:** From scratch
- **Kind of team:** Private
- **Team name:** Microsoft Service Health Hub Admin
- **Description and Classification:** Leave the default values
